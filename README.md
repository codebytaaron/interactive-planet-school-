# Veyra · A Life-Sustaining Planet

**Live planet:** https://codebytaaron.github.io/interactive-planet-school-/

Designing a Life-Sustaining Planet Project, by Teddy & George.


An interactive 3D globe of our fictional planet **Veyra**, with the full written description in cards on both sides:

- **Section 1:** Planet Overview & Geological Features (plate tectonics, all boundary types, landforms)
- **Section 2:** Atmosphere, Water & Weathering (energy source, water cycle, water's properties, weathering, erosion, nutrient cycling)
- **Section 3:** Life Ingredients (all 8 of 8)
- **Integration of Systems:** systems web, a carbon-atom loop, and a cross-section diagram
- **Rubric checklist**

Features: drag/zoom globe, search, guided tour, clickable labels, layer toggles (plates, plate-motion arrows, animated processes, life zones, clouds, night side), live coordinate/elevation/biome readout, and a print button for the written sections.
